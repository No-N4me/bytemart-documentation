# 欢迎使用 Bytemart

Bytemart 文档介绍我们为 ARK: Survival Evolved 开发的插件——如何安装、如何配置，
以及每个选项的作用。

## 从这里开始

- **[插件](plugins/index.md)** —— 插件列表、插件的安装方式，以及 `LicenseKey`、
  `Verbose`、`LogToFile` 和 `Database` 这些对所有 Bytemart 插件都通用的键。
- **[Tribescore](plugins/tribescore/index.md)** —— 竞技性的部落计分系统：安装、
  配置、命令以及配套的 Discord 机器人。
- **[ssAntiCheat](plugins/ssanticheat/index.md)** —— 服务端反作弊：安装、配置、
  命令以及封禁系统。

插件下载和许可证密钥都在你的
[Bytemart 控制台](https://bytemart.net/)中。
