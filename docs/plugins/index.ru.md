# Плагины

Плагины Bytemart расширяют возможности вашего сервера ARK новыми функциями. Каждый
плагин поставляется в виде `.zip`-архива, который вы скачиваете с вашей
**панели управления Bytemart** и помещаете в папку плагинов вашего сервера.

## Общая конфигурация

Каждый плагин Bytemart читает `config.json` верхнего уровня, в котором находится
небольшой набор общих ключей — ваш лицензионный ключ, переключатели логирования и
учётные данные для базы данных MySQL. Они задокументированы один раз, в едином месте:

- **[Общая конфигурация](common-configuration.md)** — `LicenseKey`, `Verbose`,
  `LogToFile` и `Database`, общие для **всех** плагинов.

Страница конфигурации каждого отдельного плагина описывает только те ключи, которые
уникальны для этого плагина, и ссылается на страницу выше для общих ключей.
