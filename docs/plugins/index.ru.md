# Плагины

Плагины Bytemart расширяют возможности вашего сервера ARK новыми функциями. Каждый
плагин поставляется в виде `.zip`-архива, который вы скачиваете с вашей
**панели управления Bytemart** и помещаете в папку плагинов вашего сервера.

## Доступные плагины

| Плагин | Описание |
| ------ | ----------- |
| [Tribescore](tribescore/index.md) | Соревновательная система подсчёта очков племён: племена зарабатывают очки за уничтожение вражеских построек, динозавров и игроков в PvP, с отображением через таблицу лидеров и внутриигровые голограммы. |
| [ssAntiCheat](ssanticheat/index.md) | Серверный античит: модули обнаружения боевых читов и эксплойтов, встроенная система банов с волнами банов, оповещения в Discord и исправления известных эксплойтов с крашами и дюпом. |

## Общая конфигурация

Каждый плагин Bytemart настраивается через файл `config.json`, расположенный в
собственной папке плагина:

```
ShooterGame/Binaries/Win64/ArkApi/Plugins/<PluginName>/config.json
```

Приведённые ниже ключи находятся на **верхнем уровне** этого файла и работают
одинаково во всех плагинах. Страницы отдельных плагинов документируют только те
ключи, которые уникальны для них, и ссылаются сюда для этих общих ключей.

> 💡 **Проверяйте ваш JSON.** Одна неправильно поставленная запятая или кавычка
> помешает плагину загрузиться. После каждого изменения прогоняйте свою конфигурацию
> через валидатор, например
> [JSONLint](https://jsonlint.com/). Код ошибки загрузки `1114` почти всегда
> означает синтаксическую ошибку в JSON.

### `LicenseKey`

```json
"LicenseKey": "PLACE_YOUR_LICENSEKEY_HERE"
```

Ваш лицензионный ключ Bytemart. **Обязательный.** Плагин аутентифицирует этот ключ
на лицензионном сервере Bytemart при запуске, и ни одна из его функций не
активируется, пока аутентификация не завершится успешно. Найдите свой ключ на
[панели управления Bytemart](https://bytemart.net/).

| Поле | Тип | По умолчанию | Описание |
| ----- | ---- | ------- | ----------- |
| `LicenseKey` | string | — | Лицензионный ключ, выданный для вашего плагина. Держите его в секрете. |

### `Verbose`

```json
"Verbose": false
```

Включает подробное логирование плагина. Когда установлено `true`, плагин выводит
дополнительную диагностическую информацию в консоль сервера — полезно при
устранении неполадок, но избыточно в остальных случаях. В обычном режиме работы
оставьте `false`.

| Поле | Тип | По умолчанию | Описание |
| ----- | ---- | ------- | ----------- |
| `Verbose` | boolean | `false` | Включить подробное (уровня отладки) логирование в консоль. |

### `LogToFile`

```json
"LogToFile": false
```

Когда установлено `true`, плагин дублирует всё, что он логирует, в ротируемый
файл журнала внутри собственной папки:

```
ShooterGame/Binaries/Win64/ArkApi/Plugins/<PluginName>/<PluginName>.log
```

Файл ротируется автоматически (примерно 5 МБ на файл, хранится до 3 файлов).
Записывается только вывод этого одного плагина — общий журнал ArkApi/сервера
никогда не изменяется. Это упрощает изоляцию активности одного плагина при
диагностике проблемы.

| Поле | Тип | По умолчанию | Описание |
| ----- | ---- | ------- | ----------- |
| `LogToFile` | boolean | `false` | Дублировать журналы этого плагина в его собственный ротируемый файл `.log`. |

### `Database`

```json
"Database": {
  "MysqlHost": "localhost",
  "MysqlPort": 3306,
  "MysqlUser": "username",
  "MysqlPass": "password",
  "MysqlDB": "database"
}
```

Учётные данные для подключения к MySQL. Плагины, которые сохраняют данные (таблицы
лидеров, кулдауны, транзакции и т. д.), подключаются к вашему серверу MySQL/MariaDB,
используя эти значения, и создают необходимые им таблицы при первом запуске.
Направляйте все плагины на одну и ту же базу данных, если только у вас нет
конкретной причины разделять их.

| Поле | Тип | По умолчанию | Описание |
| ----- | ---- | ------- | ----------- |
| `MysqlHost` | string | `localhost` | Имя хоста или IP-адрес вашего сервера MySQL/MariaDB. |
| `MysqlPort` | number | `3306` | Порт сервера. |
| `MysqlUser` | string | — | Имя пользователя с доступом к базе данных. |
| `MysqlPass` | string | — | Пароль для этого пользователя. |
| `MysqlDB` | string | — | Имя используемой базы данных. Она должна уже существовать; плагин создаёт внутри неё свои собственные таблицы. |

> ⚠️ **База данных должна существовать.** Плагины создают свои **таблицы**
> автоматически, но они **не** создают саму базу данных. Создайте схему с именем,
> указанным в `MysqlDB`, и предоставьте пользователю права `SELECT`, `INSERT`,
> `UPDATE`, `DELETE` и `CREATE` на неё перед запуском сервера.
