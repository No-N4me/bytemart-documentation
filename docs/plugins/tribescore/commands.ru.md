# Команды

Tribescore имеет два вида команд: **админ-команды**, запускаемые из консоли сервера
или RCON, и **игровые** чат-команды, вводимые в игре. Админ-команды имеют префикс
`ts.` и доступны только через консоль/RCON, поэтому их не защищает отдельная система
прав доступа — доступ подразумевается каналом. Чат-команды настраиваемы и
необязательны (см. [`ChatCommands`](configuration.md#chatcommands)).

## Команды консоли / RCON

| Команда | Каналы | Описание |
| ------- | -------- | ----------- |
| `ts.help [page]` | Console, RCON | Показать постраничное меню помощи Tribescore. |
| `ts.give <tribe-id> <score>` | Console | Добавить tribescore племени. Записывает транзакцию типа `system`. |
| `ts.take <tribe-id> <score>` | Console | Убрать tribescore у племени. Записывает транзакцию типа `system`. |
| `ts.boost <tribe-id> <type> <value> <duration>` | Console, RCON | Предоставить племени временный буст очков. |
| `ts.boost <tribe-id> clear` | Console, RCON | Снять активный временный буст племени. |
| `ts.audit <tribe-id> [options]` | Console | Провести аудит транзакций очков племени и загрузить отчёт. |
| `ts.estimate <recipient-tribe-id> [options]` | Console | Оценить tribescore построек вокруг вас. |
| `ts.addstructure` | Console | Добавить постройку, на которую вы смотрите, в `structures.json`. |

### `ts.give` / `ts.take`

```bash
ts.give 1234567890 500      # добавить 500 очков племени 1234567890
ts.take 1234567890 250      # убрать 250 очков у племени 1234567890
```

Обе записывают запись типа `system` в историю транзакций, чтобы ручные корректировки
можно было проверять при аудите.

### `ts.boost`

Предоставляет временный множитель очков, который встраивается в конвейер
модификаторов на заданный срок.

```
ts.boost <tribe-id> <type> <value> <duration>
ts.boost <tribe-id> clear
```

| Аргумент | Описание |
| -------- | ----------- |
| `<tribe-id>` | ID целевого племени. |
| `<type>` | К чему применяется буст: `structures`, `dinos`, `players`, `all` или комбинация, объединённая через `+` (например, `structures+dinos`). |
| `<value>` | Множитель (например, `1.5` для +50%). |
| `<duration>` | Срок действия буста, в **секундах**. |

```bash
ts.boost 1234567890 structures+dinos 1.5 3600   # +50% на постройки и динозавров на 1ч
ts.boost 1234567890 all 2 600                   # удвоить все очки на 10 минут
ts.boost 1234567890 clear                        # снять активный буст
```

> ℹ️ **Также доступно другим плагинам.** Временные бусты являются частью публичного
> API Tribescore (`SetTimedBoost` / `ClearTimedBoost` / `GetTimedBoost`), который
> сопутствующий плагин **Koth** использует для автоматического вознаграждения
> победителей событий.

### `ts.audit`

Строит асинхронный отчёт о транзакциях племени (с кого оно заработало, кто украл у
него, разбивки по кластерам) и загружает его, возвращая URL.

```
ts.audit <tribe-id> [clusters_amount=X] [givers_amount=X] [stealers_amount=X] [start_date=YYYY-MM-DD] [end_date=YYYY-MM-DD]
```

| Параметр | Описание |
| ------ | ----------- |
| `clusters_amount=X` | Количество топ-кластеров для включения. |
| `givers_amount=X` | Количество топ-племён, с которых это племя заработало очки. |
| `stealers_amount=X` | Количество топ-племён, которые забрали очки у этого племени. |
| `start_date` / `end_date` | Ограничить аудит диапазоном дат (`YYYY-MM-DD`). |

```bash
ts.audit 1234567890 givers_amount=10 start_date=2026-07-01 end_date=2026-07-12
```

### `ts.estimate`

Сканирует постройки в пределах досягаемости от вашего персонажа (через сканирование
октодеревом, разбитое на несколько тиков) и оценивает, сколько очков они принесли бы
заданному племени. Полезно для настройки значений `structures.json`.

```
ts.estimate <recipient-tribe-id> [modifiers=on|off] [range=X]
```

| Параметр | Описание |
| ------ | ----------- |
| `modifiers=on\|off` | Применять ли конвейер модификаторов к оценке. |
| `range=X` | Радиус сканирования вокруг вашего персонажа. |

### `ts.addstructure`

Выполняет трассировку луча к постройке, на которую вы смотрите, добавляет её в
`structures.json` как пользовательскую запись и выполняет горячую перезагрузку файла
— быстрый способ добавить значения по конкретным чертежам, не выискивая пути
чертежей вручную.

## Чат-команды

Они вводятся в игровом чате. Названия настраиваемы — значения по умолчанию ниже взяты
из поставляемой конфигурации [`ChatCommands`](configuration.md#chatcommands), и
каждую команду можно полностью отключить.

| Команда (по умолчанию) | Описание |
| ----------------- | ----------- |
| `/leaderboard` | Показать топ племён по очкам. |
| `/triberank` | Показать ранг и очки вашего собственного племени. |
| `/holograms` | Включить или отключить для себя плавающие голограммы `+/- points`. |

Формулировка, цвета, размер, длительность отображения на экране и (для таблицы
лидеров) количество строк и цвета для каждого ранга — всё задаётся в
[`ChatCommands`](configuration.md#chatcommands).

## Узлы прав доступа

Tribescore не использует права доступа для защиты своих команд, но функция
[`PermissionModifiers`](configuration.md#modifierspermissionmodifiers) читает узлы
прав доступа для усиления или ослабления очков племени. Выдавайте их через плагин
[Permissions](https://github.com/ServersHub/ServerAPI). С конфигурацией по
умолчанию:

```bash
Permissions.AddGroup VIP
Permissions.Grant VIP ts.boost.15
```

Здесь участник группы `VIP` даст своему племени множитель очков **1.15×**, согласно
записи `ts.boost.15` в `PermissionModifiers.Modifiers`. Имена узлов произвольны — они
просто должны совпадать с тем, что вы настроите.
